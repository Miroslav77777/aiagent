# Multi-Agent Papers Analyzer

Система на базе мультиагентной архитектуры для автоматического поиска, фильтрации и глубокого анализа научных статей в области электромембранных систем. Агенты работают строго последовательно, чтобы избежать переполнения видеопамяти (VRAM) на видеокартах уровня RTX 3060 (12GB). 

## Требования
- Docker & Docker Compose
- Локально установленный [Ollama](https://ollama.com/) с загруженными моделями:
  - `qwen2.5:7b` (для первичной фильтрации)
  - `qwen2.5:14b` (для глубокого анализа)

## Подготовка к запуску

1. **Загрузите необходимые LLM модели:**
   ```bash
   ollama pull llama3.1:8b
   ollama pull qwen2.5:14b
   ```

2. **Настройте доступность Ollama:**
   Чтобы контейнер Docker мог обращаться к локальному Ollama, сервис должен "слушать" все интерфейсы. 
   В Windows добавьте переменную среды `OLLAMA_HOST` со значением `0.0.0.0` в настройках системы и перезапустите Ollama.

3. **Создайте файл окружения:**
   Скопируйте предоставленный пример `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   # В Windows (PowerShell):
   # Copy-Item .env.example -Destination .env
   ```
   Внутри `.env` вы можете поменять логин и пароль для БД, если нужно.

## Запуск системы

В корневой папке проекта выполните сборку и запуск с помощью Docker Compose:

```bash
docker-compose up --build
```

Система автоматически:
1. Создаст базу данных PostgreSQL.
2. Скачает свежие статьи (Fetcher).
3. Отфильтрует неподходящие (Filter Agent).
4. Детально проанализирует лучшие (Analyst Agent).
5. Сгенерирует отчет с результатами.

## Где смотреть результаты?
Результаты экспортируются в формате JSON и будут доступны в папке `downloads`:
`./downloads/analyzed_articles.json`

Логи работы агентов сохраняются в папку `logs`:
`./logs/agent.log`
